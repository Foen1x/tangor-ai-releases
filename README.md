# Tangor AI official releases

[Tangor AI](https://tangor-ai.app) is an FREE All-in-One AI chat browser that can help you to remember your chat history.

Tangor is an FREE AI chat memory assistant. Powered by the system's native browser engine, it supports direct access to mainstream AI chat websites. Chat logs are automatically stored locally with millisecond-level search performance.

Fully local, always recallable, offline search available — your secrets stay yours.
